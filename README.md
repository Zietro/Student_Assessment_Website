# Student Assessment Website

## Overview

A comprehensive Student Assessment Website project developed collaboratively by a team of developers. This project emphasizes database design with a focus on creating a robust Entity-Relationship (ER) model for managing student assessments and related data.

## Project Description

This repository contains the source code for a Student Assessment Website system designed to manage, track, and evaluate student performance. The primary focus of this project was the development of a well-structured database ER model to efficiently handle assessment data, student records, and evaluation metrics.

## Key Features

- **Student Management**: Store and manage student profiles and information
- **Assessment Tracking**: Create, assign, and track various assessments
- **Grade Management**: Record and calculate student grades
- **Database Design**: Well-structured ER model for data integrity and relationships
- **Scalable Architecture**: Built to handle multiple students and assessments

## Technology Stack

- **Database**: MySQL
- **Backend**: Java (Maven), Servlet API, JSON
- **Frontend**: HTML, CSS, JavaScript
